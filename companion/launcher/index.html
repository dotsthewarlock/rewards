Get the bookmarklet
How to save and open it
  1. Open the bookmarklet link and copy the entire line, starting with javascript:.
  2. In Chrome, create or edit a new bookmark. Name it Rewards Companion and paste the complete line into its URL field. Keep your original v15 bookmark.
  3. Save it. On a supported rewards page, click the saved bookmark and choose a version. Regular may start or resume processing; do not test it on a real claim.

Keep this bookmark for future updates. If Chrome or the site blocks it, stop; do not use a console workaround.

Download Preview package
How to install the Preview
  1. Download and unzip the package. Open the included install.html for exact verification and testing instructions.
  2. Unzip the extension ZIP inside into a dedicated folder. Keep the original diagnostic tool and its data; use a separate Chrome profile for testing if practical.
  3. Open Chrome's Extensions page (chrome://extensions), enable Developer mode, choose Load unpacked and select the extension folder. Use only when authorized for testing.

Keep the downloaded package for recovery. Do not install or run overlapping rewards tools together.

Updates and help

Check your version

Open Settings → About Rewards Companion to find your version and full source ID. Older packages may show this in their included build.json file. If you cannot find the exact details, leave them unknown.

Choose how you open Companion, then a version to compare with.

Enter your exact version to compare. This page cannot detect your installed version.

Update Rewards Companion

The saved bookmark checks available versions each time. Choose which version to open each time. You do not need to replace the bookmark. For the extension, use Check your version above. The version number alone does not identify the exact build. Before updating, stop and disable the candidate, make a private backup and keep its previous verified package. Follow the new package's installation instructions. Keep the same unpacked extension folder and reload it in Chrome; do not remove the extension or clear site data just to update.

Do not switch with an unfinished or uncertain claim.

Restore a previous version

Stop if a claim is unfinished or uncertain. Keep the independent original v15 bookmark and previous verified extension package. Restore only a known safe version; do not run both at once. The original v15 bookmark is available separately if you need it and it is safe to switch.
